# `src`

Source of `quick_sort_lib`. The crate README one level up says what it is for.

- `deferred_quick_sort.rs`: the crate's source.
- `lib.rs`: Quick sort family.
- `pivot_selectors.rs`: the crate's source.
- `pivoted.rs`: `Pivoted<Scheme, Sel>`, a self-pivoting partition.
- `quick_sort.rs`: the crate's source.
- `yaroslavskiy.rs`: Dual-pivot partition, *Yaroslavskiy*'s scheme (Vladimir Yaroslavskiy), as used in the JDK's `DualPivotQuicksort`.
