# `src`

Source of `circle_sort_lib`. The crate README one level up says what it is for.

- `circle_sort_bottom_up.rs`: the crate's source.
- `circle_sort_recursive.rs`: the crate's source.
- `circle_sort_shaker_recursive.rs`: Shaker recursive circle sort.
- `directions.rs`: Bottom-up circle sort traversal directions.
- `drivers.rs`: Spec-system drivers for the circle-sort family.
- `finishing.rs`: Circle sort finishing strategies.
- `lib.rs`: Circle sort family, recursive + bottom-up, with finishing strategies.
- `orderings.rs`: Recursive circle sort orderings.
