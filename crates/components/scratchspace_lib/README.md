# `scratchspace_lib`

Scratchspace backings and what is built on them: three Auxiliary backings behind AuxiliaryMerge, the in array and fixed buffers of a block merge, the bufferless rotation merge they fall back to, the two Keys backings, three Scratchspace backings, four scripted workflows that net to identity, and the nightmare natural merge sort that runs entirely on the scratchspace contract.

Its catalog components are declared in `scratchspace.spec`.
