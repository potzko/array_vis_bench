# components

Shared components that are an axis of some family rather than an algorithm
on their own.

- `extraction_lib`: the extractions that carve a block merge sort's keys and buffer, and the stable partitions.
- `gap_distribution_lib`: gap distributions for random shell sort.
- `reverse_storage_lib`: reverse bit storage for weak heap sort.
- `scratchspace_lib`: scratchspace backings, the merges and workflows on them, the keys and buffers of a block merge, and the nightmare sort.
