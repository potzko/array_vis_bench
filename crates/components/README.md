# components

Shared components that are an axis of some family rather than an algorithm
on their own.

- `gap_distribution_lib`: gap distributions for random shell sort.
- `reverse_storage_lib`: reverse bit storage for weak heap sort.
- `scratchspace_lib`: scratchspace backings, the merges and workflows on them, and the nightmare sort.
- `comb_ratio_components` and `heap_internals_components`: empty leftovers of the retired generator, listed for deletion in `docs/todo.md`.
