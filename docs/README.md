# docs

Architecture and cross cutting documentation. Folder level detail lives in
each folder's README.

- `architecture.md`: the layering, crate graph, build and startup flow, consumers, and why the benchmark path is free.
- `registration.md`: the catalog pipeline, the `.spec` and `.avbs` references, what the emit writes, how to add a kind.
- `trait-system.md`: the role traits, the annotation traits and the logger.
- `adding-a-sort.md`: the short recipes.
- `writing-components.md`: the long form guide with a worked example.
- `todo.md`: status, open work and the decision record.
- `implementation_plans/`: designed work, started or parked.
- `llm/`: instructions for assistants.
